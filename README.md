# Многопоточная запись сообщений в журнал

Проект реализует динамическую библиотеку для записи сообщений в файл журнала и консольное приложение для проверки библиотеки.

Библиотека поддерживает:

- запись сообщений в текстовый файл;
- три уровня важности: `INFO`, `ALERT`, `FAULT`;
- фильтрацию сообщений по минимальному уровню важности;
- сохранение времени получения сообщения;
- изменение уровня важности после инициализации;
- синхронный и асинхронный режимы работы;
- ротацию файлов журнала по размеру.

Консольное приложение:

- читает строки из стандартного ввода;
- распознаёт уровень важности в начале строки;
- позволяет записывать сообщения без явно указанного уровня важности;
- поддерживает команду смены уровня важности;

---

## Соответствие заданию

Проект выполнен в соответствии со следующими требованиями:

- библиотека реализована как динамическая библиотека;
- при инициализации принимаются имя файла журнала и уровень важности;
- используются три уровня важности, заданные перечислением;
- в журнал сохраняются:
  - текст сообщения;
  - уровень важности;
  - время получения сообщения;
- уровень важности можно изменять после инициализации;
- консольное приложение принимает сообщения от пользователя;
- уровень важности может быть указан в начале строки или отсутствовать;
- передача сообщений в журнал выполняется потокобезопасно;
- запись выполняется в отдельном потоке;
- приложение ожидает новый ввод после обработки очередной строки;
- параметрами приложения являются файл журнала и уровень важности;
- используется стандарт C++17;
- применяются подходы ООП и SOLID;
- сборка библиотеки, приложения и тестов оформлена в Makefile;
- цели сборки библиотеки, приложения и тестов разделены;
- есть цель `clean`;
- сторонние библиотеки не используются.

## Формат ввода

Просто сообщение:

```text
Обычное сообщение
```

Сообщение с уровнем важности:

```text
ALERT Важное событие
```

Смена уровня важности по умолчанию:

```text
!set FAULT
```

Выход:

```text
Ctrl+D
```

или:

```text
Ctrl+C, затем Enter
```

---

## Формат журнала

Каждая запись имеет вид:

```text
[timestamp] [LEVEL] message
```

Пример:

```text
[29.07.2026 12:00:00] [INFO] Обычное сообщение
[29.07.2026 12:00:10] [ALERT] Важное событие
```

## Основные файлы

### `journal/include/IJournal.h`

Интерфейс журнала и перечисление уровней важности:

```cpp
enum class Importance { INFO, ALERT, FAULT };
```

---

### `journal/include/Journal.h`, `journal/src/Journal.cpp`

Синхронный журнал.

Отвечает за:

- фильтрацию сообщений по уровню важности;
- форматирование сообщения;
- передачу готовой строки в sink.

---

### `journal/include/AsyncJournal.h`, `journal/src/AsyncJournal.cpp`

Асинхронный журнал.

Отвечает за:

- очередь сообщений;
- рабочий поток;
- обработку команд смены уровня важности.

---

### `journal/include/FileSink.h`, `journal/src/FileSink.cpp`

Файловый вывод.

Отвечает за:

- открытие файла;
- запись строк;
- проверку ошибок записи;
- потокобезопасность.

---

### `journal/include/RotatingFileSink.h`, `journal/src/RotatingFileSink.cpp`

Файловый вывод с ротацией.

При превышении размера файла создаются архивы:

```text
journal.log
journal.log.1
journal.log.2
...
```

---

### `journal/include/SimpleFormatter.h`, `journal/src/SimpleFormatter.cpp`

Форматтер сообщений.

Создаёт строку вида:

```text
[timestamp] [LEVEL] message
```

---

### `journal/include/JournalFactory.h`, `journal/src/JournalFactory.cpp`

Фабрика для создания журнала.

Используется в приложении:

```cpp
auto asyncJournal = journal::createAsyncRotatingFileJournal(config);
```

---

### `app/main.cpp`

Точка входа консольного приложения.

Читает аргументы командной строки, создаёт журнал и запускает приложение.

---

### `app/ConsoleApplication.h`, `app/ConsoleApplication.cpp`

Консольное приложение.

Отвечает за:

- чтение строк из консоли;
- распознавание уровня важности;
- обработку команды `!set`;
- передачу сообщений в журнал.

---

### `tests/test_journal.cpp`

Тесты библиотеки:

- формат записи;
- фильтрация по уровню важности;
- смена уровня важности;
- ротация файлов;
- конкурентная запись;
- ограниченная очередь;
- исключения файлового sink.

---

### `tests/test_console_app.cpp`

Тесты консольного приложения:

- обычный ввод;
- ввод с уровнем важности;
- неизвестный уровень важноости;
- пустые строки;
- команда `!set`.
